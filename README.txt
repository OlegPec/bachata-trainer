BACHATA TRAINER v0.4 — режим обучения с готовыми треками
========================================================

1. Скопируй свои обрезанные до 1:30 песни в папку audio.
2. Для примера используй файл с точным названием:
      audio/1. Romeo Santos - Hilito.mp3
   Если у тебя другое имя — исправь поле file в tracks.js.
3. Дважды кликни index.html. Откроется тренажёр.
4. Выбери песню в списке и нажми «Играть».

Настройки песни берутся из tracks.js:
  id — уникальный ключ;
  title — название в списке;
  file — ТОЧНОЕ имя MP3 из audio;
  bpm — темп, например 117;
  offset — положение первого счёта в секундах, например 0.30;
  ready — true, когда всё проверено;
  segments — структура из обычных (normal) и дополнительных
             (appendix) долей. При [] всё считается как 1–8.

Пример схемы (НЕ разметка реального Hilito):
  segments: [
    { type: 'normal', beats: 32 },
    { type: 'normal', beats: 32 },
    { type: 'normal', beats: 32 },
    { type: 'normal', beats: 16 }, // короткий квадрат из 2 восьмёрок
    { type: 'normal', beats: 32 }  // следующий квадрат с новой «1»
  ]

ПРАВИЛО v0.4: каждый normal — отдельный квадрат/фраза. После beats:16
следующий normal начинает новый квадрат (на экране это видно).
Аппендикс не увеличивает номер квадрата. В JSON (в админке) никаких
запятых после последнего элемента массива перед ] быть не должно.


ВНИМАНИЕ:
- Сайт не распознаёт музыку автоматически: он строит счёт по заданным BPM,
  offset и сегментам. Анализатор «First beat» не всегда означает
  танцевальный счёт «раз» — перепроверь на слух.
- admin.html — отдельная пробная админка v0.4.
  Пока она НЕ изменяет tracks.js автоматически: полученные настройки
  переноси вручную. Свяжем разметку и список песен в следующей версии.
- Файлы песен НЕ включены в архив.
- Двойной щелчок по index.html работает без сервера благодаря tracks.js.
